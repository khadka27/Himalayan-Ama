# 🏠 Himalayan Ama - Luxury Apartment Rentals

Himalayan Ama is a premium web platform for booking luxury apartment rentals in **Pokhara, Nepal**. The platform allows users to explore curated living spaces, manage inquiries, and experience authentic Nepalese hospitality through a modern and responsive interface.

---

## ✨ Features

*   **Luxury Apartment Discovery:** Browse high-quality apartments with detailed descriptions and amenities.
*   **Direct Inquiries:** Seamless booking inquiry system for potential guests.
*   **Responsive Design:** Fully optimized for all devices with a premium blue and white theme.
*   **Dynamic Journal:** Travel tips and local insights from the heart of Nepal.
*   **User Reviews:** Authentic feedback from our community of guests.

---

## 🛠 Tech Stack

### Frontend

*   **Framework:** Next.js (App Router)
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS (Custom Blue & White Design System)
*   **UI Components:** Radix UI / Shadcn UI
*   **Animations:** Framer Motion
*   **Icons:** Lucide React

### Backend Integration

*   **API Client:** Axios with custom interceptors
*   **Security:** JWT-based navigation (Admin only)
*   **Real-time:** Integrated with backend flat management system

---

## 🚀 Getting Started

1.  **Clone the repository**
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run in development mode:**
    ```bash
    npm run dev
    ```

---

## ⚙️ Environment Variables

Create a `/client/.env` file with:

```env
NEXT_PUBLIC_NODE_ENV=dev
NEXT_PUBLIC_BACKEND=http://localhost:8000
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
